# 投稿168公众号榜单抓取器

本仓库持续读取公众号「短篇热榜例文-投稿168」的公开榜单及编辑例文，在 GitHub 保存可回溯的短篇市场快照。它是**数据入口**，不是替作者写稿的工具。

## 2026-11-01 起的用途与分工

- **商业短篇实验线**：重点抓公众号仍在更新的**小程序短篇**和**番茄短故事**，用于识别成熟母题、导语与冲突结构，辅助 AI 协作尝试「两天完成一篇约一万字的原创小程序风短篇投稿候选稿」。**2026年11月唯一商业结果目标：实现0→1，至少有1篇商业稿获得编辑明确过稿/签约确认**；不是每月四篇的数量考核，也不以11月收入2000元为目标。两天仅为制作效率试验，不保证过稿或回款。
- **精品创作线**：知乎短篇和用户的长篇继续按独立精品开发、审稿、修改与投稿流程推进，不受商业实验的频率或模板约束。知乎旧榜保留在历史 archive 中，不再要求它每天更新。
- 编辑例文/收稿公开信息可辅助判断供给端，但作者**没有定制编辑、没有预审开头的合作流程**。商业实验默认完整稿自行校审后再按真实投稿要求投递。

商业线顺序：**公众号例文→核验可读原作→识别成熟母题与情绪期待→一个强导语和8—12个主线节点→AI分段生成短篇初稿→只对底层因果、情绪兑现、同质化/合规作必要审查→完整稿投稿→记录编辑真实结果**。**商业稿明确采用「短、平、快、强情绪」策略**：最大限度省掉复杂设定、枝节、精密现实考据、语言雕琢与不必要的多轮讨论；仅保留读者理解故事所需的最低因果链（人物为什么行动→行动带来什么后果→情绪如何升级并兑现）。夸张可以，核心矛盾自相矛盾、人物动机断裂、明显抄袭不可以。不设定制编辑预审，投完整稿。以一篇过稿为唯一商业结果目标，若编辑回馈滞后，独立记录投稿中状态，不把等待算失败或过稿。只学方法，不换皮复制作品。

## 2026-11-04 来源纠错：黑岩故事会 ≠ 黑岩网

作者明确需要**黑岩故事会**的小程序/短篇故事样本，**不是** www.heiyan.com 的长篇小说榜。此前误加的黑岩网榜单已从 `sources.sites.json` 和采集器移除，不将黑岩长篇热榜混作黑岩故事会需求。

现有独立官网抓取器 `src/fetch_sites.py` 仅保留已确认的九州中文网 `https://jzzwxs.com/`，每日同原 Actions 定时运行并输出 `data/site_rankings/latest.json` 与历史归档。黑岩故事会目前记录为 **SOURCE_PENDING / PLATFORM_NOT_VERIFIED**：尚未验证稳定公开榜单网址、作品列表或可合法读取全文的具体入口；不得拿黑岩网结果替代，也不得声称已实现自动抓取。日后核实真实入口后再接入，不凭名称猜 URL。

**每日商业选题**：投稿168公众号小程序/番茄短篇榜 + 九州官网已验证榜单 + 黑岩故事会可核验公开短篇样本（若找到才纳入）；从中最多2篇作品核查合法免费正文范围，结合私有 `fiction-livewater-vault` 精矿/原文提炼原创机制，仅给1个首选商业短篇方向与必要备选。作者选定后ChatGPT出粗纲、8—12节精纲及关键对白，Gemini执行正文，作者终审。商业线目标11月真实过稿一篇；知乎短篇和长篇继续精品路线。

1. `miniprogram_hot`：小程序短篇、点众等相关榜单（只在原文标题确证时分类）。
2. `fanqie_short_hot`：番茄短故事/短篇，**不与番茄长篇榜混淆**。
3. `example_text`：编辑例文榜；这是例文参考，不等于真实正在收稿。
4. `submission_call`：明确的编辑征稿要求。
5. `zhihu_hot`：历史保留/可兼容，但旧栏目停更时不据此宣称每日有新知乎榜。
6. `trend_summary`：可核实的公众号概述。

配置见 `sources.json`。使用多个搜狗微信公开搜索词查找投稿168原文，允许近3天的文章补抓，以**公众号真实发布时间**给榜单排名变化定期，不以爬虫运行日伪造新榜。若公开搜索、微信页面验证或图片榜让抽取失败，就在 Actions 运行记录中报错，不绕过验证码或付费墙，也不提交空榜单文件。

## 输出与证据边界

GitHub Actions 每天北京时间17:30尝试运行（另支持手动工作流），写入：
- `data/latest.md` / `data/latest.json`：有可核验公众号榜单时更新，保留每篇原文的真实发布日期、平台、提取状态及可核实内容。
- `data/archive/YYYY-MM-DD.json`：有效榜单存档；原有2026年9月知乎记录不删除。
- `rank_history`、`rank_changes`：历史知乎，仅按真实来源时期呈现。
- `commercial_rank_changes`：小程序与番茄短故事分别独立计算。

新增可核验的公开榜：`market-intel/<榜单数据日期>/fanqie-female-new.json` 保存第三方「番茄小说趋势分析平台」的女频豪门总裁、现言脑洞新书榜前五名。页面必须明确显示数据日期和完整排名才落盘；同日内容未变化时不改写。它是**番茄长篇新书榜**，与公众号的番茄短故事榜分开，第三方在读数也不冒充番茄官方数据。

`market-intel/<抓取日期>/zhihu-story-ranking.json` 保存知乎官方盐选「故事榜」前五名的公开排名元数据。知乎接口未给出榜单生成日期，因此抓取日期不是榜单更新日期；只有排名内容变化才新建快照。作品可能包含长篇，且未核实免费试读时标记为 `UNVERIFIED`，不作为已取得正文或当日新榜的证据。

公开资料仅存**标题、公众号自带的导语/简介、必要标签、来源链接与有限元信息**；不复制收费作品全文。没有验证过的作品直链，`work_url` 留空，`work_search_url` 只作搜索入口，不能据此认定已读正文。数据只用于选题校准，不自动推导过稿概率。
